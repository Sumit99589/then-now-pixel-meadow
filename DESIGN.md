# Tracy
### One external tool. Two separate questions: what did we say, and what is true?

**Thesis.** The challenge is not merely search. “Has anything changed?” is a temporal join between an exact prior discussion and new evidence. A plausible answer to the wrong shortlist is a failure. So is treating yesterday’s assistant response as yesterday’s truth. I built one bounded, provenance-first state machine, not a multi-agent framework.

**Flow.** A request becomes: local-time resolution → historical retrieval → typed plan → parallel web search → grounded answer → validation. A small model resolves references and research scope. Simple conversation/recall can finish in that call; substantive answers use a larger model. Revalidation and high-stakes answers receive an additional evidence-entailment check. Every stage has an explicit input/output contract. Web search is the only external tool; database retrieval is application infrastructure, never an extra model-callable capability.

**Memory.** SQLite stores original messages, owner/thread identity, timestamps, immutable search-provider snapshots, content hashes, and completed results. Retrieval combines local-date windows, FTS5 lexical relevance, recent context and adjacent messages, with bounded reciprocal-rank fusion. It crosses conversations only within the authenticated browser identity. “Last Tuesday” retains both plausible interpretations until topic/context resolves them. Each local-day boundary is calculated independently across daylight-saving transitions. Originals remain authoritative; summaries are not substituted. Missing or truncated retrieval is disclosed, never converted into invented memory.

**Truth and change.** Search plans cover each requested entity **and topic**: checking five prices does not answer whether five products shipped features. Current-pricing queries deliberately avoid publication-date filters; separate announcement queries look for changes since the baseline. Evidence retains publication time and observation time separately; an effective event date requires support. Each conclusion carries exact source/message references and quoted evidence. Deterministic gates check IDs, quote existence, coverage, temporal ordering, and price-scope compatibility. A model verifier checks entailment because a valid citation can still be irrelevant. Verdicts separate verified change, support now, a prior answer needing revision, bounded “no change found,” unknown, and conflicting evidence. No-results is never proof of no-change. Verification is fallible; it is not a truth guarantee.

**Latency and failure.** Greetings need zero model calls; simple direct answers one; ordinary research normally two; revalidation normally three. Searches run at concurrency four, deduplicate within the turn, and permit one targeted gap-search round. Hard limits count physical requests, including retries: five model calls, twelve searches, ninety seconds by default. Only transient failures retry. Progress streams immediately; answer text waits for checks instead of streaming unsupported claims. Disconnects cancel upstream work. Per-thread serialization, request idempotency and atomic completion prevent duplicate or half-saved answers. Failed verification withholds conclusions. Tenant-scoped queries, opaque HttpOnly sessions, origin checks, text-only rendering and an explicit forget action protect local use; remote hosting additionally requires access control and TLS.

**Interface boundary.** The pixel-art meadow is an independent presentation layer: local SVG primitives, CSS animation, and saved visual preferences. Companions never alter prompts, tools, memory, or verdicts. Reduced-motion settings and a pause control preserve usability. Evidence remains plain text with inspectable citations; the playful shell adds no runtime dependencies or external requests.

**Choices and next week.** I rejected an agent swarm, vector database, always-on deep research, recursive self-critique and mutable “memory summaries”: each adds latency or failure modes before addressing this dataset’s core risk. Node built-ins keep runtime dependencies at zero; provider adapters and the state machine stay replaceable. The tradeoff is weaker paraphrase retrieval, synchronous SQLite at scale, conservative scope matching and model-dependent semantic verification. Tests exercise invariants and synthetic end-to-end scenarios, not live accuracy. Next week: run and independently grade the live temporal suite, measure p50/p95 latency and cost, compare against a simple search baseline, then add hybrid semantic retrieval only where measured recall failures justify it. Production work would add real accounts, encrypted retention controls and stronger injection evaluations.
